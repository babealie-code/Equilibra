# Equilibra

Carnet personnel : séances de musculation, étirements, repas, compléments et suivi du poids.

**Ouvrir l'application :** https://babealie-code.github.io/Equilibra/

- Les données restent sur ton téléphone (aucun compte, aucun serveur).
- Pour l'installer : menu du navigateur → « Ajouter à l'écran d'accueil ».
- Menus en français et en portugais (Brésil).

Les photos d'exercices proviennent de la base libre *free-exercise-db* (domaine public).
